# NeedleProof v0.1.0

NeedleProof v0.1.0 is the first hardened public release of the evidence-investigation demo built for Finance of the Future.

## Release boundary

This release freezes receipt schema 1.4, deterministic verifier v44, positive-binding contract v18, fixed-point numeric identity v1, and bounded-absence protocol v26. Their canonical versions and hashes are recorded in [`docs/contracts/v0.1.0.json`](../contracts/v0.1.0.json).

The frozen boundary guarantees only NeedleProof's documented, closed deterministic contract. It does not claim arbitrary English entailment, third-party cryptographic signing, support for confidential uploads, or production multi-tenant isolation.

## Reference specimen

The checked-in reference receipt came from a real capped GPT-5.6 Terra/medium investigation against corpus `v_0a380d3ab8d9570c`:

> What were fee-related earnings for the fiscal year?

The verified server-generated answer was:

> Fee-related earnings: $345 million.

The receipt is [`docs/reference-receipts/v0.1.0-fee-related-earnings.json`](../reference-receipts/v0.1.0-fee-related-earnings.json), has canonical SHA-256 `2687e6c21ba4a3a1238d975b53b9983950f96eb89bb6080e018810f3da144d9f`, and is bound to hardened merge commit `85a9e3189295fc094229af57f528886a09cb31c5`.

## Highlights

- One bounded corpus investigator with sequential tools and deterministic post-run verification.
- Source-resolved metric/value/time bindings with fail-closed unsupported syntax.
- Hybrid TurboVec and SQLite FTS5 retrieval over an immutable artifact-bound corpus.
- Server-owned bounded-absence proofs that revalidate exact scans against the bound corpus.
- Session-owned run access, model-spend limits, replayable SSE, lifecycle reconciliation, and application-sealed receipts.
- LiteShip 0.10.0 and Astro 7 forensic editorial interface.
- CI across Python 3.11 and 3.13, browser contracts, production build, and a Python 3.12 container canary.

## Known boundary

The public release supports the bundled public/fictional text-based PDF/TXT corpus. OCR, confidential uploads, enterprise authentication, arbitrary linguistic inference, and distributed deployment remain intentionally out of scope.
